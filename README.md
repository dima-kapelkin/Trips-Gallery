## Travel Gallery — галерея путешествий

- **Задача:** создать SPA для просмотра коллекции путешествий.
- **Что реализовано:** сетка карточек через .map(), модальное окно с детальной информацией, адаптивная верстка, компонентная структура.
- **Стек:** React, Vite, HTML5, CSS3, JavaScript (ES6+).
- **Как запустить:**
  1. Клонируй репозиторий.
  2. Выполни `npm install`.
  3. Запусти `npm run dev`.
